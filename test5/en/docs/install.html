Install and first launch

Android

  1. Open the latest release.
  2. Download Dragon-Agent-android-arm64.apk. If you're not sure about your device, take the universal file instead.
  3. Open the file and, if Android asks, allow installs from the app you used to open it.

iOS

The same release has Dragon-Agent-iOS-unsigned.ipa. It is unsigned, so install it with AltStore or Sideloadly, or sign it yourself in Xcode.

First launch

  1. Pick a provider. Google, OpenRouter, OpenAI, Anthropic, Groq, DeepSeek, Ollama, LM Studio or a custom endpoint.
  2. Connect. The base URL is pre-filled. Paste your API key; it is stored only on your device.
  3. Pick a model. Use a suggested chip or type any model id.

Using a local model? Replace localhost with your computer's LAN IP.

Updating

  1. When the device is online, and once at launch, the app checks the rolling latest release.
  2. If a newer version exists, a banner appears. Tap its update button.
  3. The APK downloads with a progress bar, then the system installer opens. It installs over the current version, so you never uninstall first.

You can also check by hand in Settings → Check for updates. On iOS the banner opens the releases page instead.
