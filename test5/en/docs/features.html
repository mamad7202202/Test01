Providers and tools

Bring your own key for Google AI Studio, OpenRouter, OpenAI, Anthropic (native), Groq, DeepSeek, Ollama or LM Studio over your LAN, or any OpenAI-compatible endpoint.

  • Deep thinking. Reasoning levels from Off to Deep, with a collapsible view of the thought process.
  • Web search. Native per provider, such as OpenRouter :online and Anthropic's server-side search.
  • Approval gate. Sensitive tools (forget, delete, rules) pause for an Allow, Always this session, or Deny card.
  • Real tool use. Memory tools, an exact calculator, date and time, and device info, each with a live status chip.
  • MCP skills. Import a SKILL.md from trusted GitHub sources and call it with /.
  • Proxy. Send AI and integration traffic through your own HTTP(S) proxy, globally or for one provider (Settings → Proxy).
  • Direct account access. With your tokens, the agent works with your GitHub (repos, pushes, PRs, Actions) and Cloudflare (KV, D1, Workers).
  • Token awareness. A small per-message usage badge from the provider.
  • Streaming. Token-by-token replies over SSE, for OpenAI-compatible and Anthropic-native APIs.
