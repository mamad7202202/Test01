Memory

The memory system is the same hybrid design as the desktop app.

  • Semantic. Discrete facts in facts.json, recalled each turn. No vector database, and it works offline.
  • Procedural. A plain MEMORY.md of standing rules that is always loaded.
  • Episodic. Every session is a transcript on your device that you can resume.
  • Compaction. Long chats are folded into dense summaries so the context never overflows.

You can switch between two engines in Settings: hybrid scored facts, or the token-efficient Outline (infographic) memory.

How facts are scored

score = tf_cosine(query, fact)
      × (0.55 + 0.45 × importance)
      × (0.7 + 0.3 × recency)

recency = 1 / (1 + age_days / 14)

The top facts are added to the system prompt each turn. Older turns are folded into a summary once the history passes the compaction threshold.
