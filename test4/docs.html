Get started

Four steps, about a minute. You need the APK and one API key.

  1. Install. Download from the latest release and sideload it. Android: Dragon-Agent-android-arm64.apk fits most phones, -universal covers the rest. iOS: install Dragon-Agent-iOS-unsigned.ipa with Sideloadly or AltStore.
  2. Pick a provider. Google AI Studio (free keys), OpenRouter (one key, many models) or Ollama and LM Studio on your own machine.
  3. Paste your key. It stays in the app’s private storage and goes only to that provider. For local models use your computer’s LAN address, like http://192.168.1.10:11434/v1, not localhost.
  4. Choose a model. Tap a suggestion or type any id, then try: “Remember that my sister’s name is Sara”.

شروع

چهار قدم، حدود یک دقیقه. فقط یک APK و یک کلید API لازم داری.

  1. نصب. از آخرین ریلیز دانلود و نصب دستی کن. اندروید: Dragon-Agent-android-arm64.apk برای بیشتر گوشی‌ها مناسب است و نسخه universal بقیه را پوشش می‌دهد. iOS: فایل Dragon-Agent-iOS-unsigned.ipa را با Sideloadly یا AltStore نصب کن.
  2. ارائه‌دهنده را انتخاب کن. Google AI Studio (کلید رایگان)، OpenRouter (یک کلید، مدل‌های فراوان) یا Ollama و LM Studio روی کامپیوتر خودت.
  3. کلید را وارد کن. کلید فقط در حافظه خصوصی برنامه می‌ماند و مستقیم به همان ارائه‌دهنده می‌رود. برای مدل‌های محلی به‌جای localhost از آدرس شبکه کامپیوترت استفاده کن، مثل http://192.168.1.10:11434/v1.
  4. مدل را انتخاب کن. یکی از پیشنهادها را بزن یا هر شناسه‌ای را تایپ کن، بعد بگو: «یادت باشه اسم خواهرم سارا است».

Memory

Two engines run on-device and offline, and one of them is injected every turn. Switching in Settings is never destructive; both stores stay on disk.

Hybrid

Facts live in facts.json. Each turn the top few are recalled with this score and injected:

score = cosine(query, fact) × (0.55 + 0.45 × importance) × (0.7 + 0.3 × recency)
recency = 1 / (1 + age_days / 14)

Outline

The same knowledge as named sections of one-line bullets. The whole outline is injected in a few hundred tokens, however much the dragon knows.

Rules

MEMORY.md holds standing rules and loads in both engines every turn. Edit it under Memories, Rules. The dragon can add a rule with remember_rule after asking you.

Sessions

Every chat is a resumable transcript. Long ones fold their oldest turns into a summary past the compaction threshold, so context never overflows.

حافظه

دو موتور حافظه روی دستگاه و بدون اینترنت کار می‌کنند و در هر نوبت یکی از آن‌ها به مدل داده می‌شود. جابه‌جایی در تنظیمات مخرب نیست؛ هر دو ذخیره روی دیسک می‌مانند.

ترکیبی

واقعیت‌ها در facts.json هستند. در هر نوبت چند مورد برتر با این امتیاز انتخاب و تزریق می‌شود:

score = cosine(query, fact) × (0.55 + 0.45 × importance) × (0.7 + 0.3 × recency)
recency = 1 / (1 + age_days / 14)

طرح کلی (Outline)

همان دانش در قالب بخش‌های نام‌دار با گلوله‌های تک‌خطی. کل آن در چند صد توکن تزریق می‌شود، هر قدر که اژدها بداند.

قوانین

فایل MEMORY.md دستورهای دائمی را نگه می‌دارد و در هر دو موتور هر نوبت بارگذاری می‌شود. آن را از «حافظه‌ها»، بخش «قوانین» ویرایش کن. اژدها هم می‌تواند بعد از پرسیدن از تو با remember_rule قانون اضافه کند.

نشست‌ها

هر گفتگو یک رونوشت قابل ازسرگیری است. گفتگوهای طولانی بعد از آستانه فشرده‌سازی، نوبت‌های قدیمی را به خلاصه تبدیل می‌کنند تا context هرگز سرریز نشود.

Tools

The dragon calls tools, and each call shows up as a chip with its arguments, result and status. Tap a chip to read the raw JSON. There is no filesystem, contacts or microphone access.

Run freely

save_memorymemory_writememory_readlist_memoriesdatetimecalculatordevice_info

Ask first

forget_memorymemory_deleteremember_rule

When one of these fires, the turn pauses and a card offers Allow once, Always (this session) or Deny. A denied call returns {"denied": true}, so the dragon adapts instead of failing. The rule: remembering is free, destroying or committing memory asks.

Commands

Typed in the message box, they run locally and spend no tokens.

  • /new Start a fresh session
  • /remember <fact> Pin a long-term fact
  • /forget <id> Delete a fact by id prefix
  • /memories Open the memory manager
  • /clear Wipe facts and bullets, keep MEMORY.md
  • /help List commands

دستورها

در کادر پیام تایپ می‌شوند، محلی اجرا می‌شوند و توکن مصرف نمی‌کنند.

  • /new شروع نشست تازه
  • /remember <fact> ثبت یک واقعیت بلندمدت
  • /forget <id> حذف واقعیت با پیشوند شناسه
  • /memories باز کردن مدیریت حافظه
  • /clear پاک‌کردن واقعیت‌ها و گلوله‌ها، بدون MEMORY.md
  • /help فهرست دستورها

Updates

The app updates itself from GitHub releases. Keys, memories and sessions survive every update.

  1. When the device comes online, and once at launch, it checks the rolling latest release.
  2. A newer version shows a banner. You can also check in Settings.
  3. Tapping it downloads the APK with progress, then opens the system installer.
  4. The new build installs over the old one.

It stacks because Android only upgrades in place when the signature and package id match and the version number grows. Every release uses the same keystore and one applicationId, with a rising build number. Builds before v1.1.0 used per-build debug keys, so uninstall those once.

Versions follow X.Y.Z+N in pubspec.yaml. Every push to main is tagged vX.Y.Z and published as a release and as the rolling latest. On iOS, Apple blocks in-app installs, so the banner opens the releases page.

به‌روزرسانی

برنامه خودش را از ریلیزهای GitHub به‌روز می‌کند. کلیدها، حافظه‌ها و نشست‌ها بعد از هر به‌روزرسانی می‌مانند.

  1. وقتی دستگاه آنلاین شود و یک بار هنگام اجرا، ریلیز latest بررسی می‌شود.
  2. نسخه جدید یک بنر نشان می‌دهد. از تنظیمات هم می‌توانی دستی بررسی کنی.
  3. با زدن بنر، APK با نوار پیشرفت دانلود می‌شود و نصب‌کننده سیستم باز می‌شود.
  4. نسخه جدید روی قبلی نصب می‌شود.

دلیل نصب روی نسخه قبلی: اندروید فقط وقتی در همان جا ارتقا می‌دهد که امضا و شناسه بسته یکی باشد و شماره نسخه بالا برود. هر ریلیز با همان keystore و یک applicationId و شماره ساخت افزایشی ساخته می‌شود. نسخه‌های قبل از v1.1.0 کلید دیباگ جداگانه داشتند؛ آن‌ها را یک بار حذف کن.

نسخه‌ها از X.Y.Z+N در pubspec.yaml می‌آیند. هر push به main با تگ vX.Y.Z هم ریلیز رسمی می‌شود و هم ریلیز متحرک latest. در iOS اپل نصب درون‌برنامه‌ای را مسدود کرده، پس بنر صفحه ریلیزها را باز می‌کند.

FAQ

Where does my API key go?
Into private storage on your phone. Requests go straight to your provider. There is no backend, analytics or telemetry.
Does memory cost extra tokens?
A little, on purpose. Hybrid injects up to six scored facts; Outline injects a few hundred tokens no matter how much it knows.
Why is web search off for my provider?
Native search exists for OpenRouter and Anthropic only. Other providers show it as unavailable instead of pretending.
Ollama won’t connect
On a phone, localhost is the phone. Use your computer’s LAN IP, keep both devices on one network and set OLLAMA_HOST=0.0.0.0.
How do I report a bug?
Open an issue on GitHub and paste the message from the in-app error screen.
