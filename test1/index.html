Get started

You need the app and one API key from any provider. The setup takes about a minute.

Install

Download a build and sideload it. Choose arm64 for most phones, universal if the installer rejects it.

Open the latest releasegithub.com

The iOS build is unsigned. Install it with Sideloadly or AltStore, or sign it yourself in Xcode. Every push to main builds fresh files in CI, so you never compile anything yourself.

Pick a provider

The first launch opens a three-step wizard. Good first choices:

  • Google AI Studio for free keys and Gemini models.
  • OpenRouter for one key that reaches hundreds of models.
  • Ollama or LM Studio to keep everything on your own machine.

Add your key

The base URL fills in for you. Your key stays in the app's private storage and goes only to the provider you picked.

Running a local model? On a phone, localhost is the phone itself. Use your computer's LAN address instead, such as http://192.168.1.10:11434/v1, and make the server listen on all interfaces.

Choose a model and talk

Tap a suggested model or type any model id. Then try:

Remember that my sister's name is Sara.

The agent calls save_memory on its own. Ask about her tomorrow and it still knows.

Make it yours

  • Appearance: light, dark or follow the system.
  • Intelligence: deep thinking, web search and temperature.
  • Memory: hybrid or outline engine, switchable any time.

Switch models mid-chat

Tap the model chip in the top bar, choose a model or type an id. The change applies from your next message and the transcript stays as it was.

Deep thinking

Set the effort in Settings, Intelligence.

  • OpenAI-compatible: the request carries reasoning_effort as low, medium or high. Models without reasoning ignore it.
  • Anthropic: a real extended-thinking budget of 2k, 8k or 16k tokens.

While the model thinks, a Thinking pill grows above the answer. Tap it to read the raw reasoning.

Web search

Search is native, never faked. OpenRouter appends :online to the model. Anthropic enables its server-side web_search tool, up to three searches per turn. Providers without search show the toggle as unavailable.

Token usage

When a provider reports usage, each answer gets a small badge such as 1.4k tokens beside the copy button.

Proxy

Settings, Proxy routes AI traffic, integration traffic or both through your own HTTP(S) proxy. Apply it globally or to a single provider.

Memory

Two engines, both on your device, both offline. Switching between them in Settings never deletes anything.

Hybrid: scored facts

Facts live in facts.json. Before every turn the best matches are recalled and added to the prompt. The agent saves new facts itself when it notices something lasting, and near-duplicates are merged.

score = cosine(query, fact)
      × (0.55 + 0.45 × importance)
      × (0.7 + 0.3 × recency)

recency = 1 / (1 + age_days / 14)

Relevance comes from word overlap. Importance and age adjust it, so a vital fact beats a newer, trivial one. At 14 days old, recency is 0.5 and the freshness factor is 0.85. Old facts fade; they never vanish.

Outline: the infographic

The same knowledge as named sections of one-line bullets. The whole outline goes into every turn, a few hundred tokens however much the agent knows.

[MEMORY OUTLINE]
profile:      Name is Sam; Lives in Lisbon;
preferences:  Short answers; Dark UI;
projects:     Learning Rust; Planning a May trip;
  • memory_write(section, bullets) adds one-liners of up to 140 characters. Near-identical bullets refresh instead of piling up.
  • memory_delete(id | section) clears stale entries, after you approve.
  • When the outline gets too large, the sections least related to your message drop first.

Anything too rich for a bullet belongs in your rules or the session transcript.

Rules: MEMORY.md

Standing instructions, loaded in both engines on every turn. Edit them under Memories, Rules, or let the agent add one with remember_rule. It always asks first.

- Always answer in Persian
- My timezone is +3:30
- Never suggest cloud services I didn't ask about

Sessions

Every conversation is a resumable transcript on your device. Reopen one from Settings, Sessions. When a chat grows past the compaction threshold, its oldest turns fold into a dense summary so the context never overflows.

The approval gate

Remembering is free. Deleting or committing memory always asks. When a gated tool fires, the turn pauses and an inline card offers three choices:

  • Allow once approves this call only.
  • Always (session) approves the tool until you close the app or start a new session.
  • Deny stops the call. The agent receives {"denied": true} and adapts instead of failing.
you      forget everything about my sister
dragon   forget_memory { "id": "a3f9" }   paused
         [ Deny ]  [ Always (session) ]  [ Allow once ]

Skills and accounts

Import any SKILL.md from trusted GitHub sources, including Anthropic's official skills repo, and invoke it with /. With your own tokens, the agent can also work in your GitHub (repos, pushes, PRs, Actions builds) and Cloudflare (KV, D1, Worker deploys).

Tokens and keys live only on your device. Nothing is connected until you add it.

Updates

The app updates itself from GitHub releases. You never uninstall to upgrade, and your keys, memories and sessions survive every update.

What happens

  1. When your device comes online, and once at launch, the app checks the rolling latest release.
  2. If a newer version exists, a banner appears over the chat. You can also check in Settings, Check for updates.
  3. Tap the banner. The APK downloads with live progress, then the system installer opens.
  4. The new version installs over the old one.

Why installs stack

Android upgrades in place only when the signature and package id match and the version number goes up. Every release uses the same signing key and one applicationId, and the build number rises each time.

One-time exception: builds before v1.1.0 were signed with a per-build debug key. Uninstall that old build once, install v1.1.0 or newer, and every update after that stacks.

Versions

  • X.Y.Z is the semantic version, set in pubspec.yaml.
  • +N is the Android build number. The updater compares only X.Y.Z, so a new build number never triggers a false update.
  • Every push to main is tagged vX.Y.Z and published as its own release as well as the rolling latest.

On iOS

Apple does not allow in-app installs. The banner opens the releases page, and you re-sideload with Sideloadly or AltStore.

    FAQ

    Short answers to the questions that come up most.

    Where does my API key go?

    Into the app's private storage on your phone. Requests go straight to the provider you picked. Dragon has no backend, no analytics and no telemetry.

    Does memory cost extra tokens?

    A little, on purpose. Hybrid mode adds the best-scoring facts. Outline mode adds a compact outline of a few hundred tokens however much it knows.

    Can it read my files or microphone?

    No. Its device tools are limited to memory, time, math and basic device info. Destructive memory actions pause and ask you first, and you can deny them mid-flight.

    Which models support deep thinking?

    Anthropic Claude with native thinking budgets, OpenAI reasoning models, and Gemini 2.5 and newer through the OpenAI-compatible layer. OpenRouter passes the setting to whatever the model supports.

    Why is web search unavailable for my provider?

    Native search exists for OpenRouter and Anthropic. Other providers show the toggle as unavailable instead of pretending to search.

    Ollama won't connect

    On a phone, localhost is the phone. Use your computer's LAN address, keep both devices on the same network, and start the server with OLLAMA_HOST=0.0.0.0.

    How do I report a bug?

    Open an issue on GitHub. If you see the in-app error screen, copy its message into the issue.

    Is it open source?

    Yes, under the MIT license: the app, the CI and this site. The desktop sibling is dragon-agent.
