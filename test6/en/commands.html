GUIDES / Commands

Chat commands and everyday controls

Type a slash command in the message field. These commands are handled by the app; they do not call the model.

Command reference

Use the exact command forms below. The id argument for /forget can be an ID prefix.

Controls in the interface

Use the new-chat button to start a session, tap the model chip to switch models, and open Settings → Sessions to resume a transcript. The memory manager is available from Settings and from /memories.

Code and answer controls

Assistant answers can be copied as Markdown. Code blocks have a separate copy control. If the provider reports token usage, the app shows it on the answer.

Command reference

CommandEffect
/newStart a fresh chat session
/remember <fact>Add a fact to the active memory engine
/forget <id>Delete a fact or outline bullet by ID prefix
/memoriesOpen the memory manager
/clearClear facts and outline bullets; keep MEMORY.md
/helpShow the command list in chat
