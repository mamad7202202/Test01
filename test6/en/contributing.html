Source code, releases, and contributing

Dragon Agent Mobile is published under the MIT License. The repository contains the Flutter app, its build workflow, and the project documentation.

Repository map

The Flutter application lives in lib/. Core provider presets and theme are in lib/core; model requests and memory stores are in lib/data; update and integration clients are in lib/services; screens and widgets are in lib/ui. GitHub Pages documentation is in docs/.

Builds and releases

GitHub Actions builds Android universal and ARM64 APKs and an unsigned iOS IPA. Pushes to main trigger the workflow; versioned tags produce formal releases alongside the rolling latest release.

Build locally

The README gives this Android/iOS project command: flutter create . --project-name dragon_agent_mobile --platforms android,ios && flutter build apk --release. Flutter and the Android build toolchain must be installed first.

Build an APK

flutter create . --project-name dragon_agent_mobile --platforms android,ios && flutter build apk --release

Contributing safely

Read the relevant code and tests, make a focused change, and run the Flutter analyzer and tests before opening a pull request. Do not use the committed release signing key for anything sensitive; the README identifies it as a public sideloading key.

Roadmap in the repository

The README lists voice input, optional embedding-backed recall, a home-screen quick-capture widget, and signed Play Store/TestFlight builds as future work. These are not current app features.

Caution

Never include API keys, private session content, or credentials in an issue, pull request, screenshot, or log.
