GUIDES / Memory & sessions

How memory and chat sessions work

Memory is stored locally and included in a model request when memory is enabled. The app offers two long-term memory formats, plus separate resumable chat transcripts.

Hybrid memory

Hybrid mode stores discrete facts and a standing MEMORY.md rules file. It scores facts against the current message using lexical cosine similarity, importance, and a two-week recency decay, then adds the best matches to the prompt.

Outline memory

Outline mode organizes short bullets under section names. The model can read, write, update, and remove outline entries through memory tools. It is intended to keep the prompt representation compact.

Sessions

Each chat session is saved as a transcript on the device and can be resumed from Settings → Sessions. Session transcripts are separate from long-term facts and rules.

Long conversations

When a conversation passes the compaction threshold, older turns are summarized by the configured model while recent turns remain in the active context. Compaction requires a working provider connection.

Review and clear

Open the memory manager from Settings → Facts, rules & outline. You can inspect and manage stored entries there. The /clear command removes facts and outline bullets while keeping MEMORY.md.

Note

Turning memory off stops memory from being injected into prompts. It does not delete saved memory or session files.
