GUIDES / Install & first run

Install Dragon Agent Mobile and connect a model

The Android build is distributed as an APK through GitHub Releases. Install it manually, then use the three-step setup wizard to choose a provider, enter connection details, and select a model.

Choose the Android APK

The release includes an ARM64 APK for most current Android phones and a universal APK for other supported Android CPU architectures. Download one APK from Releases, open it on your device, and allow your browser or file manager to install unknown apps if Android asks.

Complete the first-run wizard

Step 1: select a provider preset. Step 2: confirm its base URL and enter an API key when required. Step 3: choose a suggested model or type a model ID. The app opens the chat after setup.

Use a computer-hosted model

For Ollama or LM Studio, your phone must reach the computer over the same network. Replace localhost with the computer’s LAN IP address and make sure the model server accepts connections from the network.

Example Ollama address on your LAN

http://192.168.1.10:11434/v1

Update the app

On Android, the app checks GitHub Releases when it launches and when connectivity returns. A release banner can download the APK and open Android’s package installer. You can also check manually in Settings → Check for updates.

iOS status

The repository CI also publishes an unsigned iOS IPA. The README points to sideloading with AltStore or Sideloadly, or signing with Xcode. This site’s primary download action selects an Android APK.

Caution

Only install APKs from a source you trust. Android may ask you to grant the installer permission for the app you used to open the file.
