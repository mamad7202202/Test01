GUIDES / Providers & settings

Provider connections and app settings

Choose a preset to fill in its protocol and base URL, then provide a model ID and key where required. Dragon supports OpenAI-compatible chat endpoints and Anthropic’s native protocol.

Built-in provider presets

The app includes presets for Google AI Studio, OpenRouter, OpenAI, Anthropic, Groq, DeepSeek, Ollama, LM Studio, and a custom OpenAI-compatible endpoint. Preset model suggestions are starting points; you can type another model ID.

Provider details

The key is stored in the app’s local preferences and sent with requests to the configured provider. Dragon does not proxy model traffic through its own server. Check your provider’s pricing, data handling, and model support before connecting.

Local endpoints

The phone cannot use its own localhost address to reach your computer. Enter the computer’s LAN IP instead, including the endpoint path and port shown by the local model server.

Intelligence options

Settings includes deep-thinking effort and web search. Support depends on the selected provider and model: Anthropic uses its native thinking budget and server-side search; OpenRouter enables online search for supported models. Other endpoints may ignore or reject unsupported options.

Proxy and integrations

A separate Proxy screen can route AI traffic, integration traffic, or both through an HTTP(S) proxy. GitHub and Cloudflare integrations use tokens you provide to access those services; they are optional.

Appearance and memory

The theme can be light, dark, or follow the system. Settings also lets you choose Hybrid or Outline memory and toggle memory injection.

Tip

If a connection fails, first compare the base URL, model ID, key permissions, and provider documentation. For local endpoints, verify that the phone can reach the computer on the network.
