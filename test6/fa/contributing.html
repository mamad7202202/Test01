سورس، انتشار نسخه‌ها و مشارکت

Dragon Agent Mobile با مجوز MIT منتشر شده است. مخزن شامل برنامهٔ Flutter، workflow ساخت نسخه‌ها و مستندات پروژه است.

ساختار مخزن

کد برنامهٔ Flutter در lib/ است. تنظیمات پایه و تم در lib/core، درخواست‌های مدل و حافظه در lib/data، سرویس به‌روزرسانی و اتصال‌ها در lib/services و صفحه‌ها و ابزارک‌ها در lib/ui قرار دارند. مستندات GitHub Pages در docs/ نگه‌داری می‌شوند.

ساخت و انتشار

GitHub Actions فایل‌های APK برای Android (نسخه‌های universal و ARM64) و IPA امضانشدهٔ iOS می‌سازد. push به main فرایند ساخت را اجرا می‌کند؛ tagهای شماره‌دار release رسمی می‌سازند و کنار آن‌ها برچسب rolling latest هم به‌روز می‌شود.

ساخت محلی

README این دستور را برای ساخت Android/iOS آورده است: flutter create . --project-name dragon_agent_mobile --platforms android,ios && flutter build apk --release. ابتدا Flutter و ابزارهای ساخت Android را نصب کنید.

دستور ساخت APK

flutter create . --project-name dragon_agent_mobile --platforms android,ios && flutter build apk --release

مشارکت امن

کد و آزمون‌های مرتبط را بخوانید، تغییر محدود و مشخصی انجام دهید و پیش از pull request، analyzer و آزمون‌های Flutter را اجرا کنید. کلید امضای commit‌شده در مخزن برای نصب عمومی است و طبق README نباید برای موضوع حساس دیگری استفاده شود.

موارد آینده

README قابلیت ورود صوتی، یادآوری معنایی با embedding اختیاری، ابزارک ثبت سریع و نسخه‌های امضاشدهٔ Play Store/TestFlight را در فهرست آینده گذاشته است. این موارد هنوز قابلیت فعلی برنامه نیستند.

هشدار

API key، محتوای خصوصی نشست یا اطلاعات ورود را در issue، pull request، تصویر صفحه یا log قرار ندهید.
