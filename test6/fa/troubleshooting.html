عیب‌یابی و پرسش‌های رایج

بیشتر خطاهای اتصال از ناهماهنگی بین endpoint، شناسهٔ مدل یا تنظیم شبکه پیش می‌آیند. قبل از تغییر تنظیم‌های دیگر، این موارد را بررسی کنید.

مدل وصل نمی‌شود

مطمئن شوید API key معتبر است و اجازهٔ استفاده از مدل را دارد. نشانی پایه را با مسیر API سرویس مقایسه کنید و بررسی کنید شناسهٔ مدل برای حساب شما فعال باشد.

مدل محلی در دسترس نیست

در گوشی، localhost به خود گوشی اشاره می‌کند. IP محلی رایانه را وارد کنید، سرور مدل را اجرا نگه دارید و دسترسی شبکه را در firewall رایانه بررسی کنید. گوشی و رایانه باید بتوانند به یکدیگر وصل شوند.

APK نصب نمی‌شود

فایل را از صفحهٔ Releases پروژه بگیرید. برای بیشتر گوشی‌ها نسخهٔ ARM64 مناسب است؛ اگر معماری دستگاه چیز دیگری است، universal را امتحان کنید. ممکن است Android اجازهٔ نصب از مرورگر یا فایل‌منیجر را بخواهد.

پیام به‌روزرسانی نمی‌آید

به‌روزرسان، releaseهای شماره‌دار جدیدی را که APK دارند بررسی می‌کند و برچسب rolling latest را نادیده می‌گیرد. از Settings → Check for updates استفاده کنید یا APK را دستی نصب کنید.

چطور حافظه را پاک کنم؟

از بخش مدیریت حافظه، موارد را ببینید و مدیریت کنید. دستور /clear واقعیت‌ها و نکته‌های طرح‌واره را پاک می‌کند، اما فایل قواعد ثابت MEMORY.md را نگه می‌دارد. پاک‌کردن دادهٔ برنامه در Android ممکن است نشست‌ها و تنظیمات محلی را هم حذف کند.

گزارش مشکل را کجا بفرستم؟

برای گزارش مشکل، در صفحهٔ Issues مخزن یک issue تازه باز کنید. نسخهٔ برنامه و Android، نوع سرویس‌دهنده و راه تکرار مشکل را بنویسید؛ API key یا متن خصوصی گفت‌وگو را نفرستید.

یادداشت

خطای provider از سرویس انتخابی می‌آید. اگر پاسخ API از محدودیت درخواست یا شناسهٔ مدل نامعتبر می‌گوید، وضعیت سرویس و مستندات همان provider را ببینید.
