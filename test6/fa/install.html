نصب Dragon Agent Mobile و اتصال به مدل

نسخهٔ Android به‌شکل APK در GitHub Releases منتشر می‌شود. فایل را دستی نصب کنید و بعد در راه‌انداز سه‌مرحله‌ای، سرویس‌دهنده و نشانی اتصال را انتخاب کنید و مدل را مشخص کنید.

انتخاب فایل Android

در Releaseها فایل ARM64 برای بیشتر گوشی‌های امروزی و فایل universal برای معماری‌های پشتیبانی‌شدهٔ دیگر قرار می‌گیرد. یکی از فایل‌ها را بگیرید و باز کنید. اگر Android اجازهٔ نصب نداد، دسترسی نصب برنامه از منبع ناشناس را برای مرورگر یا فایل‌منیجر فعال کنید.

راه‌اندازی نخستین‌بار

مرحلهٔ اول: یک سرویس‌دهنده انتخاب کنید. مرحلهٔ دوم: نشانی پایه را بررسی و در صورت نیاز API key را وارد کنید. مرحلهٔ سوم: یک مدل پیشنهادی را برگزینید یا شناسهٔ مدل دلخواه را بنویسید. سپس صفحهٔ گفت‌وگو باز می‌شود.

اتصال به مدل روی رایانه

برای استفاده از Ollama یا LM Studio باید گوشی از راه شبکه به رایانه برسد. به‌جای localhost، نشانی LAN رایانه را وارد کنید و مطمئن شوید سرویس مدل درخواست‌های شبکه را می‌پذیرد.

نمونهٔ نشانی Ollama در شبکه

http://192.168.1.10:11434/v1

به‌روزرسانی برنامه

نسخهٔ Android هنگام اجرا و پس از وصل‌شدن دوبارهٔ شبکه، GitHub Releases را بررسی می‌کند. اگر نسخهٔ تازه‌ای منتشر شده باشد، با لمس اعلان فایل APK دریافت می‌شود و نصب‌کنندهٔ Android باز می‌شود. راه دیگر، انتخاب Settings → Check for updates است.

وضعیت iOS

فرایند CI مخزن یک IPA امضانشده هم می‌سازد. طبق README، نصب آن با AltStore یا Sideloadly یا امضای آن با Xcode ممکن است. دکمهٔ دریافت این سایت فایل Android را انتخاب می‌کند.

هشدار

فقط APKهایی را نصب کنید که به منبعشان اعتماد دارید. ممکن است Android برای نصب، از شما اجازهٔ ویژه بخواهد.
