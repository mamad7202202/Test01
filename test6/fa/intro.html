همراهی برای گفت‌وگو؛ با حافظه‌ای روی گوشی خودتان

Dragon Agent Mobile نسخهٔ همراه و متن‌باز Dragon Agent برای Android و iOS است. با کلید API خودتان به سرویس دلخواه وصل می‌شوید و گفت‌وگوها و حافظه را روی دستگاه نگه می‌دارید.

برنامه چه می‌کند؟

پیام شما برای سرویس مدلی که تنظیم کرده‌اید فرستاده می‌شود و پاسخ به‌صورت جریانی نمایش داده می‌شود. برنامه چند ابزار داخلی دارد، یادداشت‌های بلندمدت را نگه می‌دارد و نشست‌های قبلی را دوباره باز می‌کند.

چه چیزهایی روی دستگاه می‌ماند؟

تنظیمات سرویس، حافظه‌های ذخیره‌شده و متن نشست‌ها در فضای برنامه روی دستگاه نگه‌داری می‌شوند. Dragon Agent Mobile خودش سرویس مدل اجرا نمی‌کند؛ درخواست‌ها به سرویس یا نشانی‌ای می‌روند که شما انتخاب می‌کنید.

دو شیوهٔ حافظه

در حالت ترکیبی، واقعیت‌های جداگانه، قواعد ثابت و متن نشست‌ها ذخیره می‌شوند. در حالت طرح‌واره، نکته‌های کوتاه زیر عنوان‌های مشخص قرار می‌گیرند. می‌توانید شیوهٔ حافظه را عوض کنید یا تزریق حافظه به درخواست‌ها را خاموش کنید.

برای تنظیمات مختلف

می‌توانید از API میزبانی‌شده، نشانی سازگار با OpenAI یا مدل‌سروری در شبکهٔ محلی استفاده کنید. برای کار با این برنامه نیازی به نصب نسخهٔ دسکتاپ Dragon Agent ندارید.

یادداشت

برای سرویس‌هایی که کلید می‌خواهند، باید API key داشته باشید. Ollama و LM Studio در حالت دسترسی محلی می‌توانند بدون کلید سرویس‌دهنده استفاده شوند.
